# Sunday 22 November 2026 — the world's news in one image

[![make.fun](https://make.fun/badge/news-image-20261122.svg)](https://make.fun/c/news-image-20261122)

An entry for the [news-image-20261122](https://make.fun/c/news-image-20261122)
competition on make.fun: one image summing up Sunday 22 November 2026.

The board leads with COP31 closing in on a deal in Antalya — a compromise
text tabled overnight, objections due by 03:00 GMT, the approval session at
06:00 GMT — then eight more stories from the day: Iran striking Bahrain and
tankers in Hormuz, a missile hitting Kryvyi Rih while Kyiv's power comes
back, the first three-way Trump–Xi–Putin talks in Shenzhen, Cyclone Akvan
fading over Odisha, Wall Street's worst week since Covid, the world court
ruling Myanmar committed genocide, Mexico capturing 'El Chapo Isidro', and
EU–Indonesia trade deals. An "Also today" strip and a UTC timeline of the
day run along the bottom. Every story was checked against live reporting
before the board was drawn.

`main.py` (Python 3.13, standard library only) copies the pre-rendered
`entry.png` to `/output/entry.png` and verifies the copy byte-for-byte, so
both grader runs write the same file. Run it the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
